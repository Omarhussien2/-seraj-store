# خطة: تحويل لغة المتجر من موجّهة للأم إلى محايدة + تقسيم المقالات بحسب الجمهور

## الهدف
- إزالة الضمائر والأفعال الموجّهة للمؤنث (أنتِ، اختاري، ارفعي، شوفي، ...) واستبدالها بصياغة محايدة تناسب أي مستخدم (أب أو أم).
- إعادة تسمية "عالم ماما" إلى "عالم ماما وبابا" كـ umbrella لكل محتوى الأهل.
- إضافة taxonomy للمقالات (موجّهة للأم / للأب / للتربية عامةً) مع UI filter.
- تحديث شخصية "الجدة زينب" لتخاطب الأهل بدل الأم فقط.

## قرارات تصميمية محتاجة موافقتك

### ١. أسلوب الصياغة المحايدة
في اللغة العربية، الشكل المذكّر المفرد هو الصيغة الافتراضية (unmarked). الاقتراحات:
- **خيار A (مُوصَى به)**: استبدال الصيغة المؤنثة بالصيغة المذكّرة المفردة بنفس اللهجة المصرية:
  - `اختاري` → `اختار`
  - `ارفعي` → `ارفع`
  - `شوفي` → `شوف`
  - `ادخلي` → `ادخل`
  - `أهلاً بِكِ` → `أهلاً بيك`
- **خيار B**: استخدام صيغة الجمع (شائع في بعض المواقع العربية)
  - `اختاري` → `اختاروا`
  - `شوفي` → `شوفوا`
  - يبقى رسمي وقد يخفف الحميمية.

### ٢. إعادة تسمية "عالم ماما"
- **المقترح منك**: "عالم ماما وبابا"
- URL route يبقى كما هو `#/mama-world` (backward compatible).
- الأيقونة والـ hero image قد نحتاج تحديثهما (الصورة الحالية للجدة زينب جالسة).

### ٣. شخصية "الجدة زينب" (AI chat)
الحالية: جدة مصرية تخاطب الأمهات بصيغة المؤنث (`أنتِ`, `يا حبيبتي`, `يا ست الكل`).
- **خيار A (مُوصَى به)**: الإبقاء على شخصيتها كجدة مصرية حكيمة، لكن تخاطب الوالد/الوالدة بصيغة محايدة. تستخدم `يا حبيبي` / `يا ابني` / `يا بنتي` حسب السياق، وتخاطب "الأهل" بدل "الأمهات" في وصف دورها.
- خيار B: إضافة شخصية ثانية "الجد عمر" للآباء (تضاعف العمل).
- خيار C: شخصية واحدة جنسها مبهم (الاسم "زينب" سيظل، لكن بأسلوب أكثر محايدة).

### ٤. حقل audience للمقالات
إضافة حقل `audience` لنموذج `Article` مع قيم:
- `mother` — موجّه للأم
- `father` — موجّه للأب (فارغ حالياً، سيُملأ لاحقاً)
- `parenting` — تربية عامة بدون استهداف جنس
- `general` — محتوى غير تربوي (اختياري)

UI: chips/tabs فوق شبكة المقالات داخل "عالم ماما وبابا" لفلترة حسب الجمهور.

### ٥. تقسيم إلى PRs
- **PR A**: تحييد النصوص (تعديلات مكثفة على ملفات نصية، بدون تغييرات معمارية)
- **PR B**: إعادة تسمية عالم ماما → عالم ماما وبابا
- **PR C**: إضافة حقل audience + UI filter + admin editor
- **PR D** (اختياري): تحديث prompt الجدة زينب

## خطة التنفيذ المقترحة

### PR A: تحييد النصوص  (~3-4 ساعات كود)
**ملفات**: `public/index.html`, `public/app.js`, `src/lib/seed/contentDefaults.ts`
1. سيناريو regex-assisted pass على كل الملفات للعثور على الأفعال المؤنثة الشائعة.
2. مراجعة يدوية مع الحفاظ على النغمة الودودة (الطفولية).
3. تحديث `window.IS_FEMININE` — لا يوجد حاليًا، لكن سنتجنب أي افتراضات.
4. **بدون** تعديل DB مباشرة: تحديث defaults فقط. لو المحتوى الحي مختلف في DB، admin ممكن يعدّله.
5. اختبار محلي: فتح الموقع، التأكد من أن كل النصوص الظاهرة محايدة.

### PR B: إعادة تسمية عالم ماما (~30 دقيقة)
- نص `nav.mama` + `mama.hero_title` + `mama.hero_desc` + h3 في zigzag row
- URL `#/mama-world` يبقى
- aria-labels + alt text
- لا تغييرات في admin أو DB

### PR C: حقل audience للمقالات (~2-3 ساعات)
1. إضافة `audience` في `src/lib/models/Article.ts` (default: `"mother"` للقديم، `"parenting"` للجديد)
2. migration سكريبت لتحديث المقالات الموجودة
3. إضافة chips فوق articles grid في الـ frontend
4. تحديث `src/app/admin/articles/page.tsx` لإضافة dropdown
5. تحديث `scripts/seed-articles.ts` لتعيين الـ audience لكل مقال seed

### PR D: تحديث الجدة زينب (~1 ساعة)
- تعديل SYSTEM_PROMPT لتخاطب الأهل عموماً (مع استخدام صيغة محايدة)
- تحديث few-shot examples
- تحديث label الـ tab `اسألي زينب` → `اسأل زينب`
